QWERTYTERNITY — an Eviternity-style raycaster

Eviternity-scale procedural floors. Every run is a new seed. Die, and the run is gone. Clear a floor, pick an upgrade, go deeper. Doom movement: momentum, friction, and view bob.

Q dash   T throw bomb   P pause   M mute   N new run (on death)   E use (door / pushwall / elevator) / glory kill a staggered enemy
QWERTY tip: strafe with Q/E? No — Q is dash, E is nothing. Strafe is A/D while turning with the mouse. That's the QWERTYTERNITY way.
Find the glowing [EXIT] portal on each floor. Kills give XP. Level up: press 1 / 2 / 3 to pick an upgrade.
Phone: left pad = move stick, right pad = drag to look (tap it to fire), FIRE / DASH / BOMB / JUMP buttons below. Also works by touch on the game itself: left half drag = move, right half drag = look, tap right = fire.
Joypad: plug in any standard gamepad (Xbox / PlayStation / Switch Pro / 8BitDo) and press a button — left stick moves, right stick looks (push up/down to look up/down), RT or A fires, X meat hooks (Super Shotgun), B dashes, Y bombs, LB/RB change weapon, Start pauses. On upgrade screens LB/RB pick, A confirms.
